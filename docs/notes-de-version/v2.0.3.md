# Barbacane v2.0.3

Reprise des correctifs d'usbsas (CEA) dans le noyau, sécurité d'abord. Non encore étiquetée.

## Noyau : nouvelle base `cea-sec/usbsas` `c75c7eb` (21/11/2026)

Les 151 commits amont depuis `69ebcf4` ont été rejoués un par un sur le noyau (un commit
« noyau : reprise amont <commit> » chacun ; détail dans [ecarts.md](../noyau/ecarts.md)).

- **dev2scsi** (série du 20-21/11) : lectures refusées hors du périphérique ou plus grandes qu'un
  message, table de partitions lue avec une taille bornée, partitions listées même si l'une est
  illisible, secteurs de 4 Kio, détection ISO 9660 limitée aux descripteurs et au début de la
  partition, processus isolé (seccomp) même sans périphérique ouvert, tests unitaires.
- **comm** : descripteurs de tubes reçus par l'environnement validés (`75171e5`), tests unitaires.
- **seccomp** : comparaisons 32 bits masquées (`6bd82f1`, identique à notre ancien écart 1),
  `getrandom` pour l'imageur.
- **net** : https et TLS 1.3 obligatoires, 3 redirections au plus, pas de gzip vers l'analyseur et le
  téléversement, taille des réponses bornée, délai de chaque envoi calculé sur sa taille
  (`tcp_user_timeout` de 30 s), mêmes limites pour le téléchargement.
- **usbsas** : profondeur maximale des fichiers d'une source (`max_depth`, 20 par défaut, dossiers
  au-delà signalés dans le rapport), journaux plus complets, rapport écrit en plusieurs fois,
  espace libre vérifié avant un téléchargement réseau.
- **fsrw** (ntfs3g, ff, 02/11) : déjà présents depuis l'écart 3 ; features par défaut retirées.
- **Dépendances** : features par défaut inutiles retirées dans tout le noyau, `env_logger` retiré là
  où il ne servait pas, crates à jour ; **nix 0.32** (dependabot) via l'amont ; **jiff 1.0**
  (dependabot) dans `barbacane-analyzer` et `barbacane-admind` (`Zoned` devient `ZonedDateTime`).

Non repris : la réécriture de `usbsas-analyzer-server` (la borne a son propre analyseur), le client
graphique amont, la documentation et les fichiers de la racine amont.

## Écarts du noyau

- Devenus inutiles : 1 (seccomp masqué), 3 (reprise fsrw), 8 (délai de 12 h, remplacé par le délai
  amont proportionnel à la taille), 10 (étiquette FAT12/16, version amont `893c004`).
- Conservés : 2, 4, 5, 6, 7 (réécrit sur la détection amont `is_iso9660`), 9 (suit le renommage
  `scsi_write`), 11.
- Nouveau **12** : l'amont refuse toute URL `http://` ; la borne parle à son analyseur sur
  `http://127.0.0.1:8042`. Seules les URL http vers une adresse IP de bouclage sont acceptées, sans
  redirection ; tout le reste exige https et TLS 1.3 (la feature `allow-http` n'est pas activée).
- Documenté **13** : `ppoll`/`poll` dans le fil udev (v2.0.1), absent jusque-là de la liste.

## Configuration de la borne

`poll_timeout = 43200` dans `[analyzer]` de `/etc/usbsas/config.toml` : l'amont attend le résultat
d'analyse 30 min par défaut, trop peu pour une clé de plusieurs Go.
