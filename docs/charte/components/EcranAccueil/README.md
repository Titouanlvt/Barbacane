# EcranAccueil

Accueil de la borne : emblème en veille (15 i/s, arrêt après 2 min), consigne, emplacement des lecteurs.

Maquette à 1280 × 768 (résolution minimale). Captures Jour et Nuit : `maquettes/EcranAccueil-jour.png`, `maquettes/EcranAccueil-nuit.png`. Construite uniquement avec `bundle.css` (et les séquences 3D) : ce qui s'y voit est réalisable tel quel.
