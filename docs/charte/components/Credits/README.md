# Credits

Bloc qui cite les projets sur lesquels repose Barbacane : usbsas (CEA-SEC), ClamAV (Cisco Talos), YARA (VirusTotal). Noms en Barlow Condensed, rôle en une ligne, éditeur, licence et adresse en mono.

Où l'afficher : écran « À propos » de l'administration, bas du README GitHub, documentation. Jamais sur les écrans du parcours utilisateur.

Logos des projets : on ne les redessine pas et on ne les recolore pas. Pour les afficher, utilisez les fichiers officiels tels quels, après avoir vérifié les conditions d'usage de chaque marque, sur un fond `surface-haute` neutre, à la même hauteur que les noms (32 px). Sans fichier officiel, le nom en texte suffit. La mention « non affilié » reste obligatoire.
