# ServeurEnrolement

Interface web, enrôlement d'une borne : formulaire, erreur de validation, double validation annoncée, étapes à côté.

Maquette à 1280 × 768 (résolution minimale). Captures Jour et Nuit : `maquettes/ServeurEnrolement-jour.png`, `maquettes/ServeurEnrolement-nuit.png`. Construite uniquement avec `bundle.css` (et les séquences 3D) : ce qui s'y voit est réalisable tel quel.
