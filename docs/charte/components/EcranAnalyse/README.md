# EcranAnalyse

Analyse : la clé, la barre vivante, les compteurs sains / bloqués / écartés en direct, « Annuler l'analyse » en bas à gauche.

Maquette à 1280 × 768 (résolution minimale). Captures Jour et Nuit : `maquettes/EcranAnalyse-jour.png`, `maquettes/EcranAnalyse-nuit.png`. Construite uniquement avec `bundle.css` (et les séquences 3D) : ce qui s'y voit est réalisable tel quel.
