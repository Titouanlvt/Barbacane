# EcranBloque

Résultat avec menace : panneau bloqué, liste des fichiers bloqués puis écartés, herse fermée, et ce qui peut quand même être copié.

Maquette à 1280 × 768 (résolution minimale). Captures Jour et Nuit : `maquettes/EcranBloque-jour.png`, `maquettes/EcranBloque-nuit.png`. Construite uniquement avec `bundle.css` (et les séquences 3D) : ce qui s'y voit est réalisable tel quel.
