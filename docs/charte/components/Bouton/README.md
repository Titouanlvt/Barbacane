# Bouton

Trois variantes, 72 px de haut minimum (`cible-min`), texte en Atkinson Hyperlegible 700 à 24 px.

- **Principal** : fond `encre`, texte `sur-encre`. Un seul par écran, en bas à droite.
- **Secondaire** : contour `encre`, fond transparent. « Annuler », « Retour ».
- **Destructif** : fond `menace`. Uniquement « Effacer cette clé », toujours suivi d'un écran de confirmation.

Le focus est un anneau `laiton` de 4 px décalé de 4 px. Libellé = verbe + objet (« Copier vers la clé de destination »), jamais « OK » ou « Valider ».
