# AnimGravure

Gravure d'un disque : le disque tourne, l'anneau gravé s'élargit, la tête laser suit la progression réelle.

Storyboard minuté, règles et justification : section **Animations** (`animations.md`), « 6. Gravure d'un disque ». L'aperçu boucle ; la case « Version réduite » montre l'état affiché avec l'option « Animations réduites ».

- **Version réduite** : Disque immobile ; anneau et tête suivent la progression.
- **Rendu logiciel** : Bande `disque` (18 images) + deux ellipses + un rectangle ; ≈ 240 × 160 px.
