# AnimInsertion

Insertion d'une clé : la clé pivote vers la porte, glisse, s'enfonce ; le voyant passe au laiton.

Storyboard minuté, règles et justification : section **Animations** (`animations.md`), « 1. Insertion d'une clé ». L'aperçu boucle ; la case « Version réduite » montre l'état affiché avec l'option « Animations réduites ».

- **Version réduite** : Clé en place, voyant allumé, texte affiché.
- **Rendu logiciel** : Bande `cle` (16 images) + translation ; ≈ 520 × 200 px par image pendant 1 s.
