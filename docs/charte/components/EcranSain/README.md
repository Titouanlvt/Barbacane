# EcranSain

Résultat sain : panneau de verdict (niveau 3) et choix de la suite en cartes ; Blanchir se distingue par le rouge et son texte.

Maquette à 1280 × 768 (résolution minimale). Captures Jour et Nuit : `maquettes/EcranSain-jour.png`, `maquettes/EcranSain-nuit.png`. Construite uniquement avec `bundle.css` (et les séquences 3D) : ce qui s'y voit est réalisable tel quel.
