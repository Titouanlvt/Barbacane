# AnimSain

Verdict sain : le bouclier se tourne vers l'utilisateur, deux ondes, le panneau se pose.

Storyboard minuté, règles et justification : section **Animations** (`animations.md`), « 3. Verdict sain ». L'aperçu boucle ; la case « Version réduite » montre l'état affiché avec l'option « Animations réduites ».

- **Version réduite** : Bouclier de face et panneau, sans onde.
- **Rendu logiciel** : Bande `bouclier` (14 images), anneaux pré-tramés à 3 tailles, couleur par paliers.
