# Etapes

Bandeau d'étapes en haut de chaque écran du parcours. Étapes faites en `encre` avec une coche, étape en cours sur `laiton-pale` soulignée `laiton`, étapes à venir en `encre-douce`.

Non cliquable : la borne impose l'ordre, on ne revient en arrière qu'avec le bouton « Annuler ». Masqué sur l'écran d'accueil.
