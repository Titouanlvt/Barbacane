# Champ

Champ de saisie de niveau −1 : fond `surface-creuse`, bord `trait-fort` (3:1), ombre intérieure en haut, arête de lumière en bas. Il se lit comme une case creusée dans la pierre, où l'on dépose quelque chose.

- Étiquette au-dessus, en gras, toujours visible (jamais seulement en texte indicatif).
- Aide en dessous, `encre-douce`. En erreur : bord `menace` de 2 px, message `menace` précédé de « ✕ » (la couleur n'est pas le seul signal), qui dit quoi faire.
- Focus : anneau `laiton` 3 px.
- Borne : 64 px de haut, texte 26 px espacé (PIN, identifiant) ; saisie au clavier virtuel uniquement.
- Web : 40 px, texte 15 px. Listes déroulantes et cases à cocher suivent le même niveau.
