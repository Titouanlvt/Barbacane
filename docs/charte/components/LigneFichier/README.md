# LigneFichier

Une ligne par fichier dans la liste du verdict. Chemin relatif en JetBrains Mono 18 px, détail (signature détectée ou raison du rejet, puis taille) en `encre-douce`, badge d'état aligné à droite.

N'afficher par défaut que les fichiers **Menace** puis **Écarté** ; les fichiers sains se résument dans le bandeau (« 1 038 fichiers copiés »). Les chemins longs passent à la ligne, jamais tronqués : c'est le seul moyen pour l'utilisateur de reconnaître son fichier.
