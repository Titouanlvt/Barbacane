# ServeurSupervision

Interface web, page d'accueil : tuiles, « À traiter », tableau des bornes. CSS seul.

Maquette à 1280 × 768 (résolution minimale). Captures Jour et Nuit : `maquettes/ServeurSupervision-jour.png`, `maquettes/ServeurSupervision-nuit.png`. Construite uniquement avec `bundle.css` (et les séquences 3D) : ce qui s'y voit est réalisable tel quel.
